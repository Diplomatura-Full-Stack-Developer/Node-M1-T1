### Pasos para la ejecución local:

1. Clonar el repositorio:

```bash
git clone https://github.com/Diplomatura-Full-Stack-Developer/Node-M1-T1
```

2. Instalar las dependencias:

```bash
npm install
```

3. Ejecutar el script:

```bash
node app.js
```
